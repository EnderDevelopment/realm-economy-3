# Realm Economy

Realm Economy is a Minecraft Bedrock Edition behavior pack that provides a complete, reliable, multiplayer-compatible economy system for your Realm. It allows players to earn, manage, and spend currency, participate in jobs and quests, and compete on leaderboards. The system uses Minecraft scoreboards for currency storage and dynamic properties for additional persistent data, ensuring it works even when the Realm owner is offline.

## Install

1. Download the Realm Economy behavior pack.
2. Place the behavior pack in the `behavior_packs` folder of your Realm.
3. Start or restart your Realm to enable the behavior pack.

## Use

1. Players can earn currency by completing jobs and quests.
2. Use the `/balance` command to check your current balance.
3. Use the `/pay <player> <amount>` command to transfer money to other players.
4. Use the `/shop` command to access server shops and buy or sell items.
5. Use the `/jobs` command to view available jobs and quests.
6. Use the `/leaderboard` command to view the top players on the leaderboard.
7. Use the `/history` command to view your transaction history.
